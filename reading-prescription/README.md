# 독서 처방전 (Reading Prescription)

고민을 입력하면 독서클럽 보유 도서와 확장 도서 중 3권을 추천하는 정적 웹앱입니다.

## 기능
- 고민 입력 → 추천 도서 3권
- 저자, 추천 이유, 한 줄 처방, 복용법
- 책 표지 검색 및 교보문고 검색 링크
- 전체 결과 복사, 최근 20개 상담 기록의 브라우저 로컬 저장
- 111개 클럽 도서 목록 항목 + 확장 도서 10권, 18개 고민 유형

## 실행

```bash
cd reading-prescription
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## Vercel 배포
Vercel에서 `thunder13c/Front-end`를 연동하고 프로젝트 Root Directory를 `reading-prescription`으로 지정하세요. Framework Preset은 `Other`, Build Command는 비우고, Output Directory는 `.`으로 설정합니다.

현재 버전은 키워드 기반의 규칙 추천이며 생성형 AI API는 사용하지 않습니다. 고민 내용은 브라우저 내부에서만 처리되며 최근 20건 기록은 localStorage에 저장됩니다.


## v2 - 개인 고민/키워드 관리
- 내장 버튼 12개와 직접 추가한 버튼(최대 100개)을 클릭하면 해당 고민과 주제로 바로 3권을 추천합니다.
- '키워드 추가·관리'에서 이름·고민 문장·추천 주제(18개 기본 + 선택과 집중)를 등록, 수정, 삭제할 수 있습니다.
- 개인 설정은 localStorage에만 저장됩니다. 브라우저/기기 간 공유하려면 JSON 내보내기/가져오기를 사용합니다.
- 도서는 독서클럽 보유목록 111개 항목에 외부 확장 도서를 추가했습니다. 표지는 Google Books에서 조회하고 교보문고 검색 링크를 제공합니다.
- 보안: 입력 문자열은 textContent로 렌더링하며 API 키나 로그인 없이 동작합니다.

## v3 복합 키워드 추천
- 여러 고민 버튼을 선택하면 ` + ` 구분자로 고민 문장을 합치고 최대 3개 주제를 함께 분석합니다.
- 서로 다른 고민을 골고루 반영하고 동일 도서 중복을 방지합니다.
- 결과별 무작위 시드에 의해 관련성이 있는 후보의 조합이나 순서가 달라집니다. 출처의 근거 자체가 바뀌는 생성형 AI 방식은 아닙니다.
- 도서 표지는 Google Books HTTPS 이미지 URL에서 불러오며, book.coverUrl이 HTTPS인 경우 해당 URL을 우선합니다. 표지는 교보문고 검색 URL로 연결합니다. 교보문고 상세 링크나 교보문고 공식 표지 URL을 검증한 기능은 아닙니다.
- 기존 localStorage 기록 키는 변경하지 않습니다. 기존 기록은 이전과 같은 도메인/브라우저에서 유지됩니다.

## v4 · 책별 줄거리와 다양한 독서 관점
- 추천 대상 전체 39권에 대해 `book-insights.json`에 요약 소개와 3개 독서 관점(공감/재질문/적용)을 수록했습니다.
- 결과 카드의 **책의 내용 · 다양한 독서 관점 펼치기**를 누르면 자세한 내용을 확인할 수 있습니다.
- 장르에 따라 소설은 줄거리, 시집은 소개, 비문학은 핵심 내용으로 표기합니다.
- 상세 처방 복사 버튼은 기존 한 줄 처방에 책별 소개와 관점을 추가해 복사합니다.
- 독서 관점은 실제 독자 후기/원문 인용이 아닌 상담용 해석 예시이며, 소설은 반전 등을 노출하지 않는 수준으로 작성했습니다.
- 기존 브라우저 기록 키(`reading-prescription-history-v1`)와 사용자 프리셋 키(`reading-prescription-presets-v2`)는 유지됩니다.
- 책별 소개는 도서클럽의 서지정보와 도서 소개 자료 등을 참고해 편집한 간략한 설명이며, 원문 전문을 수록하지 않습니다.
